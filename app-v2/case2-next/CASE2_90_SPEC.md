# CASE2 90点基準ケース仕様

## 学習到達目標

- 校則を「自由か禁止か」の二択にせず、目的・必要性・影響で検討できる。
- 個人の尊重と自由は、他者の安全や学習環境との調整が必要だと説明できる。
- 事実・人権・理由・改善案をつなぎ、根拠ある提案をつくれる。

## 固有ゲームループ

1. 見習いクイズ2問：合否判定ではなく、調査の観点を受け取る。
2. わいわい聞き込み：三つの立場を聞き、意見と事実を分ける。
3. 比較ミッション：校則ごとに目的と証拠を対応させ、維持・見直しを判断する。
4. 事件簿：事実＋人権＋理由＋改善の4カードを接続する。
5. 成長：能力「比べる」を解放し、教室の納得度と法子の成長を可視化する。

## 90点合格条件

- 3タップ以内に人物の反応が返る。
- 誤答は罰音ではなく、ヒント→再判断になる。
- 少なくとも3種類の操作（会話、証拠選択、組み立て）を含む。
- 最終回答は単一選択でなく、理由の接続を必要とする。
- キャラクターの顔と反応をUIが隠さない。
- 1ケース5〜7分、iPad横画面とタッチ操作に対応する。
- CASE固有の絵・音・演出がある。

## 公民王との差別化

- 公民王：知識を武器に敵を倒す。
- 法子：知識を調査道具に、人の声をつないで問題を改善する。

# 法子とけんぽうくんの事件簿｜見習い編

中学校社会科・公民の人権学習ゲーム。2026年11月3日、生徒配布版。

## 生徒への配布

https://t-miyako36.github.io/kenpo-rpg/

このURLをロイロノートのWebカードに貼って配布します。ログイン・インストールは不要です。

1. 「物語をはじめる」で自己紹介・出会い・相棒テストへ。
2. 6事件を解決し、卒業テストへ。
3. 15問中9問以上で合格。得点率に応じた称号とエンディングへ。
4. 卒業後に条文シューティングを開放。40問から10問、ノーマルは三択、ハードは日本語入力。

## 記録と音声

- 進み具合は同じ端末・同じブラウザーに自動保存。「続きから・ステージを選ぶ」で再開できます。
- 保存先は従来と同じで、既存の本編の記録・称号を保持します。別端末への同期はありません。
- BGMは初回ON。画面のボタンで切替可能。音声は最初の操作後に再生します。正誤効果音あり。
- テスト用入口・比較・効果音切替・動き切替は生徒画面に表示しません。旧リンクの `test=1` は取り除き、通常版で開きます。

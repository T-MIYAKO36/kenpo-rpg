# 法子とけんぽうくんの事件簿 V4 制作仕様

## 学習目標

人権の歴史、日本国憲法の基本原則、人権の分類を理解し、身近な事件で「事実・権利・理由・より負担の小さい解決」を使って判断できる。

## 全体構成

1. プロローグ
2. 基礎訓練A「消えた人権の歴史」
3. 基礎訓練B「憲法の設計図」
4. 選択式の6事件
5. 特別訓練「奪われた権利を取り戻せ」
6. 卒業試験（知識5問・人権マップ・未知事件）
7. エンディング

## 成長ランク

| 条件 | ランク | 法子の役割 |
|---|---|---|
| 0〜1件 | 新人見習い | けんぽうくんに教わる |
| 2〜3件 | 事件調査見習い | 関係する人権を予想する |
| 4〜5件 | 准・人権調査員 | 調査と判断を主導する |
| 6件＋特別訓練 | 卒業試験 | 未知事件に挑戦する |
| 卒業合格 | 人権事件調査員 | 自分の言葉で助言する |

事件の順番は固定せず、解決数で成長する。事件選択画面上部の成長ルートを法子のミニアイコンが移動する。

## 共通事件ループ

1. 20秒以内の事件発生
2. 依頼人への聞き込み
3. 知識獲得操作
4. 事件固有ミニゲーム
5. 最終判断
6. 解決会話・事件記録獲得

初回5〜8分、再調査3〜5分。誤答はヒント後に再挑戦し、2回誤答時は理由を示す。

## 学習配置

| 場面 | 必須概念 |
|---|---|
| 訓練A | 社会契約説、三権分立、人権宣言、ワイマール憲法、世界人権宣言、明治憲法と日本国憲法 |
| 訓練B | 国民主権、基本的人権の尊重、平和主義、最高法規、普遍性・永久不可侵、人権6分類 |
| CASE1 | 国民主権、参政権、選挙、多数決と少数意見 |
| CASE2 | 平等権、精神の自由、経済活動の自由、公共の福祉 |
| CASE3 | 生存権、教育、勤労、労働基本権、社会保障、子どもの権利 |
| 特別訓練 | 身体の自由、令状、黙秘、適正手続、裁判、請願、国家賠償、刑事補償 |
| CASE4 | プライバシー、個人情報、知る権利、情報公開、表現との調整 |
| CASE5 | 平和主義、9条、自衛権、条文と政府見解、必要最小限度 |
| CASE6 | 個人の尊重、幸福追求権、自己決定、説明・理解・熟考・本人意思 |
| 卒業事件 | 外国人・子ども・少数者、合理的区別と不合理な差別 |

## 画面品質

- 中央パネルは横幅58%前後に抑え、法子・けんぽうくん・依頼人を隠さない。
- 会話は下部ウィンドウを使い、中央には操作対象だけを置く。
- 見出しは従来V2より25〜30%縮小する。
- iPad横向きで16:9を維持し、主要ボタンは44px以上とする。
- BGM・効果音はV1を基準に復元し、ミュートでも進行できる。
